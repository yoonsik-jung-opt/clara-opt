# CLARA

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Classical LP Analysis for Reoptimization and Attribution**

A white-box optimization solver that explains why solutions are optimal, when reoptimization is needed, and what changed.

## Installation

```bash
pip install clara-opt
```

For development:

```bash
git clone https://github.com/yourusername/clara-opt.git
cd clara-opt
pip install -e ".[dev]"
```
